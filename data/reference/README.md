# Reference data

The original material-attribute reference file is not distributed.

For local execution of Script 008, create:

`material_attributes.xlsx`

with a worksheet named `MATERIAL_ATTRIBUTES` and the following anonymized
columns:

- `MATERIAL_DUMMY`
- `GROUP_DUMMY`
- `PROMO_ONLY`
- `CATEGORY_DUMMY`
- `VENDOR_DUMMY`

Do not commit the real reference file.
